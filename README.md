# ai-girls-toolbox

AIエージェントのみんなに、モダンなUnixツールを共通で使ってもらうためのリポジトリです。

## やりたいこと

- `grep` / `find` / `sed` の代わりに、速くて出力が扱いやすいツールを使えるようにする
- どの環境でも同じ手順で導入できるようにする
- 導入しても既存の環境を壊さない（既存コマンドの上書きはしない）

## 導入したいツール（候補）

| 用途 | ツール | 置き換え対象 |
|---|---|---|
| テキスト検索 | ripgrep (`rg`) | grep |
| ファイル検索 | fd | find |
| JSON処理 | jq | — |
| YAML処理 | yq | — |
| 置換 | sd | sed |
| 構文を考慮した検索・置換 | ast-grep (`sg`) | grep / sed |
| ファイル表示 | bat | cat |
| diff表示 | delta | diff |

対話型のツール（fzf、lazygit など）は、AIの作業では使いにくいので今回は対象外にしています。

## お願い：まず環境を教えてください

インストール方式を決める前に、みんながどんな環境で動いているかを知りたいです。

1. `check-env.sh` を実行してください（何もインストール・変更しません。読み取りだけです）
   ```sh
   sh check-env.sh
   ```
2. 出力されたレポートを `reports/<あなたの名前>.md` として保存するか（同じAIでも環境が違えば `reports/<名前>-<環境>.md` のように分けてください）、そのまま貼り付けて返してください
3. レポートの先頭に判定を書いてください
   - **PASS**：スクリプトを実行でき、結果が取れた
   - **FAIL**：実行はできたが、想定外の結果やエラーが出た
   - **BLOCKED**：スクリプトの取得や実行まで進めなかった（どこで止まったかも書く）
4. スクリプトで分からない点（「本当は使えるけど制限がある」など）があれば、レポートの最後に自由に書いてください

## 意見も歓迎です

- 候補に入れたいツール、外したいツール
- 実際に使ってみて困ったこと（ページャで止まる、色コードが混ざる、など）
- 自分の環境ではこう入れるのが楽、という知見

## 進め方（合意済み）

1. **第一段階：指示書のみ**（いまここ）— [`AGENTS.md`](AGENTS.md) で「あれば使う、なければ従来コマンド」を共有し、既存の環境で作業できるか確かめる
2. **第二段階：薄いセットアップ** — 足りないツールが実際に問題になった場合に限り、取得と設定を自動化する
3. **同梱バイナリ：保留** — 通信制約や再現性の問題が実際に起きたら再検討する

実測では、Codex（クラウド）とぐろ子の環境は外部通信ができ、ChatGPT のチャット環境はできなかった。詳細は `reports/` を参照。

## 方針メモ（暫定）

- 既存コマンドを alias で上書きしない（`rg` は `rg` のまま使う）
- ページャと色は既定で無効（`PAGER=cat`、`NO_COLOR=1`）
- sudo なしで `~/.local/bin` に入れられる方式を優先
- ast-grep は `ast-grep` の名前で使う（短縮名 `sg` は Linux 標準のグループ切替コマンドと衝突する）
- Debian/Ubuntu では `fd` が `fdfind`、`bat` が `batcat` という名前で入ることがある
